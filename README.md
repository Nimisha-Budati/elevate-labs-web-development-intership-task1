# 🌐 Web Development Internship - Task 1

## 📌 Project Title
Simple Responsive Landing Page using HTML & CSS

---

## 🎯 Objective
To build a clean, responsive landing page using HTML5 and CSS3 with proper layout structure including header, navigation bar, hero section, and footer.

---

## 📁 Project Structure
Task1/
├── index.html
├── about.html
├── services.html
├── contact.html
├── style.css
├── logo.jpg
└── README.md

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries

---

## ✨ Features
- Responsive navigation bar
- Multi-page website (Home, About, Services, Contact)
- Hero section with heading, paragraph, and button
- Footer with social media links
- Mobile-friendly design using media queries
- Clean and simple UI design

---

## 📱 Responsive Design
- Desktop: Horizontal navigation bar and full layout
- Mobile: Stacked navigation and adjusted font sizes
- Implemented using CSS media queries (max-width: 768px)

---

## 🚀 How to Run the Project
1. Download or clone the repository
2. Open the project folder in VS Code
3. Run `index.html` using Live Server
   OR
4. Open `index.html` directly in any web browser
